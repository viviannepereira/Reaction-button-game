# Reaction-button-game
### **Overview:**
Game that calculates players reaction time based on how long they take to press a button when 
an LED flashes. There are three rounds, average reaction time is displayed at the end.

### **Hardware:**
* Arduino Uno or similar
* Breadboard
* Male to male wires
* LCD display
* Potentiometer 
* 220 ohm resistor
* LED
* Button/switch
